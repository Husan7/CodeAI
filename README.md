# CodeAI

**Understanding large codebases just got easier.**  
In software development, a significant portion of a developer's time—up to 60%—is spent not in writing code, but in reading and understanding existing codebases. This task becomes even more hectic when the code is vast, large, and lacks proper documentation. 
 CodeAI is a solution that addresses major pain points of developers. CodeAI acts like a senior developer, helping you understand large codebases easily. You can ask any doubts and queries you have about the codebase (eg: Where is razorpay API called in ? or explain razorpay API function and different functions dependencies), and not only that, but it also generates documentation for you and your teammates :D

Auto Documentation: Generates up-to-date documentation for the entire codebase automatically, turning a once tedious task into a seamless process, and making the code much easier to understand for current and future developers.
Debugging: CodeAI enhances code quality by identifying inefficiencies and suggesting optimizations. With the user's approval, it can even initiate merge requests to implement these improvements, ensuring the codebase remains efficient and robust.
Codebase Design Map: To further aid comprehension, CodeAI offers visual maps of the code ecosystem, enabling developers to quickly grasp the structure and relationships within the codebase. This visual aid accelerates feature development and debugging, making the development process more efficient.

How Easy it is to use?
Insert GitHub Username : User inputs their GitHub username.
Select Repository : User selects a repository from their GitHub account.
Get Auto Documentation for Repo : CodeAI automatically generates documentation for the selected repository.
Get Design Codebase Map of Repo : CodeAI generates a visual map of the codebase structure for the selected repository.
Talk To Repo Codebase : User interacts with CodeAI to ask questions or seek clarification about the codebase.
Debugging: Streamlines the process of code improvement by automating the generation and sending of merge requests.
